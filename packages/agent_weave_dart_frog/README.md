# agent_weave_dart_frog

Dart Frog handlers for AgentWeave chat, owner-scoped history and typed generation.
Authentication provides the trusted owner and application context. The chat and
generation streams use server-sent events.

Development version, not published to pub.dev yet. Requires Dart 3.12.2 or later.

See the [Dart Frog guide](https://github.com/seifalmotaz/agent-weave/blob/main/docs/dart-frog.md)
and [offline example](https://github.com/seifalmotaz/agent-weave/tree/main/examples/dart_frog).

Independent and unofficial. Not endorsed by Dart Frog or TanStack.
